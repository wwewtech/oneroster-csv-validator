Validation Pipeline

Manifest & Structure

Ensures manifest.csv exists at the root, accurately describes the files present, and enforces core file presence for bulk exchanges.

Bulk vs Delta Discipline

Validates strict file modes. Bulk rows must exclude dateLastModified and status. Delta rows require them. Mixed files fail fast.

GUID Integrity

Traces every sourcedId across files. Prevents orphan references in enrollments or classes, ensuring data consistency without inventing missing IDs.

Enrollment Sanity

Verifies classes have primary teachers and active students. Differentiates between active syncing rows and inactive/deleted records.

Encoding Traps

Detects stripped leading zeros (Excel corruption) and enforces UTF-8 compliance, protecting against accidental student creation/deletion.

Output Report Format

The validator produces clear, actionable findings reports rather than silently altering files.
